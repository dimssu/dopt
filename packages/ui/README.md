# @clinical-notes/ui

Shared design system. Tokens (`color`, `space`, `radius`, `typography`, `motion`, `elevation`) and primitives (`Button`, `Card`, `Badge`, `Input`, `TranscriptBubble`, `CitationLink`, `EmptyState`).

Aesthetic direction: Linear meets Epic. Restrained colour, one accent, heavy on typography and spacing rhythm. Tokens are semantic — components reference roles, never hexes. Storybook target lives in `pnpm storybook`.

Owned by `ui-ux-designer` (tokens, motion, typography decisions) and `frontend-engineer` (implementation).
